# Communication Preferences

## Layers

1. **NotificationPreference** — per recipient (customer or staff) channel toggles + marketing flags
2. **CustomerCommunicationPreference** (CRM) — synced from guest preference updates for email/sms/push
3. **CustomerConsent** — required for marketing purposes

## Guest UI

Transactional: In-App, Email, Push (+ optional SMS)  
Marketing: Email, SMS, Push (off by default; requires consent to deliver)

Transactional/essential in-app notifications remain available for operational messages unless business rules say otherwise.
